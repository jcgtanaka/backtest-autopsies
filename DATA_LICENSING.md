# Data licensing

This repository publishes code and derived results. It does
not publish market data. The MIT licence in `LICENSE` covers the code only.

## What is published

- Code: the `autopsy_common` package, the notebooks and the tools.
- Executed results: metrics, test statistics, equity curves and charts that
  are derived outputs.
- Schema: column names, dtypes, units and key descriptions (`data_schema.md`
  in each case).
- A synthetic sample: fake data with the same schema, fixed seed, round
  values, generated by the code.
- Nothing that measures the input data: no row counts, input date ranges,
  distinct counts of instruments, contracts or dates, content hashes or
  per-asset breakdowns. Strategy results (trade counts, out-of-sample periods,
  metrics) are results, not input data, and are published.

## What is never published

- Historical data files of any vendor, in any format or size.
- Raw rows: no table previews, no `head()` or `tail()` of real data, no
  date-and-price rows in outputs or text.
- API keys, tokens, account identifiers, local paths or user names.

The `.gitignore` excludes data folders and data file types, and
`tools/publish_gate.py` fails the build if any of the above appear.

## Vendor terms: not verified

The published cases use or were built from data of these sources:

- Interactive Brokers
- yfinance (public daily equity closes downloaded by the reader)

The author has **not verified** the terms of any of them for redistribution,
derived data, display or public sharing. Until that check is done and written
down:

- no vendor rows are published, and
- the input data is described by structure only (columns, types, units, key,
  frequency, source recipe); its size and contents are not described.

## If you want to reproduce a case

- Obtain the data yourself, under your own licence and subscription with the
  vendor. The schema files describe the columns the notebooks expect.
- Point `AUTOPSY_DATA_DIR` to your local folder. Nothing is downloaded or
  uploaded by the repository.
- Or use synthetic mode (`AUTOPSY_SYNTHETIC=1`), which needs no external data
  and does not reproduce the published failures.
- No keys are stored in this repository. If a downloader needs credentials it
  must read them from environment variables.
